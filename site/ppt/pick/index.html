      下载模板

      1. 一个 zip：这一组的母版 .pptx、6 页预览图、写好的提示词，和一份「先读我」。
      2. 解压后，把母版、预览图和你自己的文档一起上传给智能体，再把「提示词.md」全文粘贴发送。
      3. 可选：智能体装了 GarmanPPT 技能会更稳。看 技能介绍页（含下载和安装方法），或直接到 GitHub 下载。
